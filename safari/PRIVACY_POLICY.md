# NYCU E3 Helper Privacy Policy

Effective date: 2026-10-14. Applies to the macOS and iPadOS Safari apps, including version 3.0.1.

NYCU E3 Helper is an unofficial helper for NYCU E3. It provides Safari sidebar features and an offline demo. It is not affiliated with or operated by the university.

## Data on your device

The extension stores course and assignment data, grades, membership information, announcements, messages, read/submission status, notification history, preferences, diagnostic logs, translations and AI results locally in browser extension storage. User-provided Gemini and OpenAI API keys are also stored locally. Treat access to your device and browser profile as access to these settings.

Live E3 access uses your existing signed-in Safari session and makes requests to E3. The helper does not ask you to provide your university password to its developer. E3 authentication and data handling remain subject to the university's policies.

## Optional translation and AI

Translation transmits relevant text to Google Translate. AI summaries transmit item content to your selected Gemini or OpenAI service with your API key. Daily digests include titles, courses, senders and timestamps. AI connection tests and Gemini model discovery also contact the selected service.

OpenAI summary requests set `store: false`, but standard API abuse-monitoring logs may retain submitted content for up to 30 days, with exceptions described by OpenAI. Unpaid Gemini API services may use inputs and outputs to provide, improve and develop Google services and machine-learning technologies; human reviewers may process that data. Paid Gemini services follow different data-use terms. Do not send sensitive, confidential or personal information to unpaid Gemini services. Provider processing, retention, account settings, costs and quotas are governed by its policies. E3 content may contain personal information; use optional services only for content you are permitted to share.

Submitted text can include announcement/message content, sender names, email addresses or identifiers present in that content. AI requests authenticate using your provider key, so requests may be associated with your provider account/project. The helper does not anonymize submitted text. It does not intentionally use this data for advertising tracking.

The app is intended for adult university users (18+). Gemini API use is subject to Google's minimum age of 18 and other service eligibility requirements. The app does not implement age verification or parental controls.

- Google privacy: https://policies.google.com/privacy
- Gemini API terms: https://ai.google.dev/gemini-api/terms
- OpenAI privacy: https://openai.com/policies/privacy-policy/
- OpenAI API data controls: https://platform.openai.com/docs/guides/your-data

## Demo mode

The offline demo uses fictional data and local translation, summary and notification samples. Demo storage is separate from live extension storage; demo requests do not contact E3, Google Translate, Gemini or OpenAI. Reset samples resets demo data only.

## Notifications, downloads and support

macOS desktop notifications require permission and may display E3 information. iPad uses sidebar alerts. Downloaded files are saved/shared using platform file tools; saved copies remain under your control.

The reviewed implementation has no developer-operated analytics or advertising service. If you voluntarily submit an issue or share logs, GitHub receives what you submit. Remove student names, messages, grades, session tokens and API keys before sharing. GitHub's policies govern that service.

## Your choices and deletion

Disable AI summaries, remove saved API keys in settings and save, revoke keys with the provider, disable the Safari extension or revoke website permissions. Disabling a feature does not automatically erase previously saved data or keys. Reset samples erases demo edits only.

To erase local extension data, remove the extension/app and use browser or OS storage-removal controls where necessary. Separately delete exported files, backups and support submissions. Deleting a local key does not erase provider-held data; use the provider's controls for that data.

## Contact and updates

Questions: https://github.com/Yoyo1112/portal_e3_helper/issues. Do not post private academic information or credentials in public issues. Update this policy when data handling changes.
