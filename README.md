# NYCU E3 Helper

繁體中文 · [English](README.en.md)

整合陽明交通大學 E3 學習平台的作業、課程、公告、信件與教材，讓日常課程資訊集中在同一個側欄。

[Chrome 線上應用程式商店](https://chromewebstore.google.com/detail/nycu-e3-helper/cmagonljljocpkfojkabhiedjafamoef) · [E3 平台](https://e3p.nycu.edu.tw/) · [更新日誌](CHANGELOG.md)

本文件對應目前儲存庫的原始碼；商店版本可能尚未包含最新修改。

## 功能特色

- **淺色側欄**：白與淺灰介面、靛藍重點色、單色 SVG 圖示，以及清楚的字級與字重層次。浮動入口可上下拖曳，側欄寬度可調整並記憶。
- **作業管理**：截止倒數、繳交狀態、自訂作業，以及編輯、刪除與作業頁面連結。
- **課程資訊**：課程列表、成員統計、成員變動與成績資訊。
- **公告與信件**：整合課程公告與 dcpcmail 信件，支援類型、已讀狀態篩選及全文預覽。
- **今日總覽**：在公告頁上方一次整理今天公告與信件的重點，附上原文連結；使用 OpenAI 摘要設定。
- **翻譯與單篇摘要**：中英翻譯使用 Google Translate，不需要 API Key；單篇 AI 摘要使用 OpenAI。
- **教材下載**：掃描目前頁面或選取課程，勾選檔案後分開下載或打包 ZIP。
- **通知與背景同步**：集中顯示作業、評分、公告與成員變動提醒，並顯示未讀徽章。
- **版本更新通知**：升級後顯示版本變更，也可從通知中心回看。

## 安裝

### 從商店安裝

到 [Chrome 線上應用程式商店](https://chromewebstore.google.com/detail/nycu-e3-helper/cmagonljljocpkfojkabhiedjafamoef) 安裝擴充功能。

### macOS Safari

macOS Safari 的 Xcode 專案、簽署與測試方式請見 [Safari 安裝與開發指南](safari/README.md)，上架準備請見 [App Store 指南](safari/APP_STORE.md)。Safari 版透過原生橋接使用 macOS 桌面通知，需允許 NYCU E3 Helper 的系統通知；側欄通知仍可使用。

### 載入原始碼

適用於 Chrome、Edge 或 Brave：

1. 下載或複製儲存庫：

   ```bash
   git clone https://github.com/Yoyo1112/portal_e3_helper.git
   cd portal_e3_helper
   ```

2. 開啟瀏覽器的擴充功能管理頁：Chrome 使用 `chrome://extensions/`，Edge 使用 `edge://extensions/`，Brave 使用 `brave://extensions/`。
3. 開啟「開發人員模式」，點「載入未封裝項目」，選擇包含 `manifest.json` 的專案資料夾。
4. 開啟一般網頁，點右側的「E3 Helper」入口。

更新本地程式碼後，請先在擴充功能管理頁重新載入擴充功能，再重新整理已開啟的網頁。瀏覽器內部頁面與部分受限制頁面無法注入側欄。

## 介面與首次使用

支援繁體中文與英文介面。首次使用會依瀏覽器語言選擇；在「更多 → 設定 → 介面語言」選擇繁體中文或 English，再點「儲存設定」。變更語言後會重新整理目前頁面，其他已開啟頁面需手動重新整理。語言偏好儲存在瀏覽器本地；課程名稱與公告原文保留原文，AI 摘要與今日總覽依所選介面語言產生。

1. 登入 [E3 平台](https://e3p.nycu.edu.tw/)。
2. 點浮動入口開啟側欄，再點頂欄「同步」載入作業與課程。
3. 切換分頁查看資料；同步時間顯示在「E3 Helper」標題下方。

| 入口 | 用途 |
| --- | --- |
| 作業 | 截止倒數、繳交狀態與自訂作業 |
| 課程 | 課程列表、統計與成績 |
| 下載 | 掃描並下載教材與其他檔案 |
| 公告 | 今日總覽、公告與信件、閱讀狀態與內容預覽 |
| 通知 | 作業、評分、公告、成員變動與版本提醒 |
| 說明 | 側欄內的操作指南與問題排除 |
| 更多（頂欄三點按鈕） | 設定、查看日誌與問題回報 |

浮動入口可上下拖曳，拖曳側欄左緣可調整寬度。主要內容使用 14px 字級，輔助資訊使用 12px；標題、按鈕與內文採不同字重，避免整頁粗體。

## 日常操作

### 作業

- 點作業卡片開啟作業頁面。
- 點「標記為已繳交」切換狀態；再點「已繳交」可改回待處理。
- 用「新增作業」加入自訂作業，也可用卡片上的「編輯」與「刪除」管理作業。
- 截止日期與倒數使用本地時區。倒數顏色依剩餘時間區分：一天內紅色、超過一天至三天琥珀色、超過三天至七天藍色、超過七天綠色；已截止項目以灰色顯示「已截止」。
- 已繳交且過期的作業會從列表隱藏；刪除 E3 同步作業後，後續同步仍可能重新載入。

### 公告與信件

- 開啟「公告」分頁載入資料；已有資料時可點「重新載入」更新。
- 「類型」可篩選全部、公告或信件；「狀態」可篩選全部、未讀或已讀。
- 未讀項目有紅點標記。點「查看內容」預覽全文，可切換閱讀狀態或「開啟完整頁面」。
- 「全部已讀」一次標記所有公告與信件為已讀。
- 內容頁可使用「中→英」、「英→中」、「AI摘要」，以及「顯示原文」。

### 今日總覽

公告分頁最上方有獨立的「今日總覽」區塊，點「產生總覽」即可整理今天的公告與信件。

1. 先載入公告與信件，必要時點「重新載入」。
2. 在「更多 → 設定」啟用 AI 摘要並儲存 OpenAI API Key 與模型。
3. 回到公告分頁，點「產生總覽」，等待重點與來源連結出現。

總覽依本地日期選取今天的項目，最多整理最新 40 則，不受下方類型或閱讀狀態篩選影響。沒有今天的資料時會顯示提示；產生失敗後可再次點擊重試。

總覽根據項目標題、課程、寄件者與時間整理，並非逐篇閱讀全文。完整內容、作業要求與截止時間請以原文為準。

### 課程與成績

先同步課程資料，再到「課程」分頁選取課程。課程詳情提供「統計」與「成績」，可查看成員資訊及評分資料。資料載入需有效的 E3 登入狀態。

### 下載教材

1. 到「下載」分頁，選擇「掃描此頁」或「選擇課程」。
2. 掃描此頁時，請先切換到對應 E3 頁面；選擇課程時，勾選要掃描的課程。
3. 勾選掃描結果中的檔案，再點「分開下載」或「打包下載」。

支援 PDF、簡報、文書、試算表、影片與壓縮檔等格式。下載期間會顯示進度；大型檔案可分批處理。

### 通知

「通知」集中顯示作業、評分、公告與課程成員變動等提醒。浮動入口與瀏覽器工具列徽章顯示未讀數量；24 小時內到期且尚未繳交的作業也會列入提醒。版本更新通知可用來回看變更內容。

### 通知與提醒時間設定

到「更多 → 設定 → 設定通知與提醒時間」，或從瀏覽器擴充功能管理頁開啟選項。

- 用「桌面通知」開關啟用電腦／瀏覽器通知；「測試通知」可確認瀏覽器與系統是否允許通知。
- 「公告與信件」可獨立勾選；新作業與評分會自動提醒。首次公告與信件同步作為基準，不為歷史資料發出桌面通知。
- 截止前提醒使用下拉選單，提供 30 分鐘、1／3／6／12 小時、1／2／3 天及一週。預設為一天與一小時，可新增或移除多個提醒；移除所有時間即可關閉截止提醒。已繳交、刪除、截止時間已變更或已截止的提醒會略過。
- 可選「即時通知」或「每天固定時間」。每日模式依電腦本地時區，在下一個指定時間逐則送出待處理通知；截止提醒也受此設定影響，已截止項目會略過。
- 調整後點「儲存設定」，下方會顯示目前設定與儲存結果。關閉桌面通知不影響側欄通知中心。

背景每分鐘檢查通知；瀏覽器關閉時無法顯示桌面通知，休眠可能延後。新資料取決於 E3 同步週期與登入狀態。佇列最多保留 200 則，最近 2000 個已處理事件用於去重。通知設定與資料保留在瀏覽器本地。

## AI 設定

### 啟用 OpenAI 摘要

1. 開啟側欄頂欄的「更多 → 設定」。
2. 勾選「啟用 AI 摘要」。
3. 填入自己的 OpenAI API Key，選擇摘要模型。
4. 點「儲存設定」；可用「測試 OpenAI 摘要」檢查連線。

同一組設定用於單篇「AI摘要」與「今日總覽」。模型選項以目前介面為準；API 使用資格、費用與額度依自己的服務帳戶設定而定，本專案不保證免費額度。

### 翻譯

「中→英」與「英→中」使用 Google Translate；英文翻成中文時使用繁體中文。翻譯不需要 OpenAI API Key，也不依賴 AI 摘要開關。翻譯流程會保留原有 HTML 結構；如需確認完整內容，可切回原文或開啟來源頁面。

目前摘要功能使用 OpenAI，翻譯使用 Google Translate，不需要設定 Gemini API。

## 同步行為

| 資料 | 背景同步週期 | 手動入口 |
| --- | --- | --- |
| 作業與課程 | 每 60 分鐘 | 頂欄「同步」 |
| 課程成員變動 | 每 60 分鐘 | 課程中的相關檢測操作 |
| 公告與信件 | 每 30 分鐘 | 公告分頁載入或「重新載入」 |

側欄開啟時也會檢查作業與課程的同步時間，超過 5 分鐘會觸發更新，並定期檢查。實際完成時間受瀏覽器執行狀態、網路與 E3 登入狀態影響。

公告與信件同步會優先使用已開啟的 E3 分頁；沒有 E3 分頁時，會暫時建立未啟用的背景分頁取得資料，完成後關閉。看到 E3 分頁短暫出現再關閉可能是正常同步行為。詳見 [v2.1.1 同步行為說明](CHANGELOG.md)。

一般網站也能開啟助手、查看已儲存資料與透過背景載入 E3 資料；連線載入仍需要有效登入，掃描目前頁面的教材則需在對應 E3 頁面操作。

## 資料與隱私

- 課程資料、作業狀態、閱讀狀態、AI 設定與 API Key 儲存在瀏覽器本地。
- 使用翻譯時，待翻譯文字會傳送至 Google Translate。
- 使用單篇摘要時，待摘要內文會傳送至 OpenAI。
- 使用今日總覽時，今天項目的標題、課程、寄件者與時間會傳送至 OpenAI。
- OpenAI 摘要請求由背景服務呼叫 Responses API，並設定 `store: false`。
- 本擴充功能不要求提供 E3 密碼，而是使用瀏覽器既有的 E3 登入狀態。

## 常見問題

**同步或載入失敗？**

先確認已登入 E3，再檢查網路並重試。登入過期時需重新登入。頂欄同步主要更新作業與課程，公告與信件請在公告分頁重新載入。

**找不到今日總覽，或沒有今天的資料？**

先到公告分頁載入資料；有公告或信件後，入口位於篩選區上方。總覽只選取本地日期為今天的項目，並需先設定 OpenAI 摘要。

**摘要失敗？**

到「更多 → 設定」確認已啟用 AI 摘要、填入有效金鑰並儲存。用「測試 OpenAI 摘要」檢查連線，再依錯誤訊息處理模型、帳戶額度或網路問題。

**翻譯失敗？**

翻譯使用 Google Translate，請檢查連線並重試；不需要重新設定 OpenAI 金鑰。若內容顯示不完整，可用「顯示原文」或「開啟完整頁面」。

**更新擴充功能後沒有新版介面，或提示功能失效？**

在擴充功能管理頁重新載入後，還需要重新整理原本已開啟的網頁。

**ZIP 下載失敗或無法開啟？**

檢查網路與 E3 登入狀態，再分批選取檔案重試；也可改用「分開下載」或前往來源頁面下載大型檔案。

**如何回報問題？**

側欄頂欄「更多 → 查看日誌」可查看操作記錄；「更多 → 問題回報」可提交回報。分享日誌前請檢查其中是否包含不想公開的課程或個人資訊。

## 開發與除錯

### 專案結構

```text
portal_e3_helper/
├── manifest.json          # Manifest V3 設定與權限
├── background.js          # 背景同步、下載與 OpenAI API 代理
├── content.js             # 側欄、資料顯示、翻譯與互動
├── jszip.min.js           # ZIP 打包函式庫
├── 128.png                # 擴充功能圖示
├── README.md              # 操作與開發指南
├── CHANGELOG.md           # 歷史版本變更
├── INSTALL.md             # 安裝文件
├── USER_NOTICE.md         # 使用者告知
└── STORE_DESCRIPTION.txt  # 商店說明
```

目前直接使用 JavaScript 與 DOM/CSS，不需要前端建置步驟。修改後以未封裝擴充功能重新載入並驗證。

### 除錯入口

- **側欄日誌**：更多 → 查看日誌。
- **頁面 Console**：開啟瀏覽器開發者工具，查看 `E3 Helper:` 訊息；頁面日誌攔截只在 E3 網站啟用。
- **背景服務 Console**：在擴充功能管理頁點 Service Worker 的檢查入口，查看背景同步與 API 錯誤。

在擴充功能的 Service Worker Console 中可讀取本地資料：

```javascript
chrome.storage.local.get(
  ['assignments', 'courses', 'announcements', 'messages', 'lastSyncTime'],
  console.log
);
```

### 修改後的檢查

```bash
node --check content.js
node --check background.js
git diff --check
```

請驗證六個分頁、280／350／800px 側欄寬度、作業管理、閱讀狀態、同步、下載、翻譯與 AI 摘要。確認空資料、載入中、失敗與成功狀態，以及鍵盤焦點和宿主頁面樣式。
